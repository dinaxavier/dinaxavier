   → Criar Service Account

   → Criar planilha com 6 abas
   → Compartilhar com service account
   
   Guia: SETUP_APIS.md seção 1

2. Configurar Kiwi API (~10 min)
   → Criar conta: https://tequila.kiwi.com
   → Criar aplicação
   → Copiar API Key
   
   Guia: SETUP_APIS.md seção 2

3. Configurar .env
   GOOGLE_SHEETS_ID=seu-id
   GOOGLE_APPLICATION_CREDENTIALS=./credentials.json
   KIWI_API_KEY=sua-key

4. Testar Integrações
   cd /workspace/voos-milhas-monitor
   node testar-integracao.js
   
   Esperado: "🎉 Todas as integrações estão funcionando!"

5. Testar no Playground
   npx @grok/agent-sdk serve --dir . --mode single --dev
   
   Abrir: http://127.0.0.1:3000/playground
   Testar: "Busque passagens de GRU para CDG"
